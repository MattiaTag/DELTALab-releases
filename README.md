# DELTALab

**DELTALab** is free desktop software for processing and standardising clumped isotope
data: Δ47, Δ48, δ13C and δ18O. It imports Thermo Isodat `.did` files, Qtegra CSV exports
and legacy Easotope databases, and runs on macOS and Windows.

- **Website, user guide and downloads:** <https://mattiatag.github.io/DELTALab-releases/>
- **Latest release:** <https://github.com/MattiaTag/DELTALab-releases/releases/latest>
- **All releases:** <https://github.com/MattiaTag/DELTALab-releases/releases>

## Installing

- **macOS:** download the `.dmg` for your chip (`aarch64` for Apple silicon, `x64` for
  Intel), drag DELTALab to Applications and open it.
- **Windows:** download `x64-setup.exe` and run it.

Updates install from inside the app. This repository holds the released builds; the
website and the user guide are published from it as well.
